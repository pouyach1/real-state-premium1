# Derakhshan Premium source

The source is split by page without changing the existing HTML, CSS, or JavaScript behavior.

```text
src/
  pages/
    home.html
    console.html
  styles/
    home.css
    console.css
  scripts/
    home.js
    console.js
```

Open `src/pages/home.html` for the public page and `src/pages/console.html` for the management console.
The original root HTML files remain available as compatibility entry points.
